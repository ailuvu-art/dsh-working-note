Fix OAuth callback on staging Chat

Login trên staging đang redirect sai. Chạy dev server giúp tôi rồi hướng dẫn tôi test tay nhé.

Tôi đã start backend và web dev server trong background, cả hai đang lắng nghe:

✓bashuvicorn app.main:app --port 8000job-3f91
✓bashpnpm dev --port 5173job-8ad2

Các bước cần bạn làm tay:

  • Mở http://127.0.0.1:5173/login và bấm Continue with GitHub.
  • Quan sát network tab: request tới /auth/callback phải trả về 302 tới /dashboard.
  • Sau đó chạy pnpm test:e2e -- auth trong terminal của bạn và dán log lại vào chat.

Đoạn ni cần kiểm tra thêm: session token phải được set với SameSite=Lax, không được dùng SameSite=None vì Safari sẽ chặn.

Ghi chú đã được ghim vào Working Note — bấm vào thanh ghim phía trên ô chat để xem.

Đã mở trang, bấm GitHub xong nó redirect về /auth/callback?error=state_mismatch.

Đúng như nghi ngờ — state cookie bị mất giữa hai request. Tôi vừa sửa middleware và commit nháp:
